# VERY BASIC CLI TEXT EDITOR

A very basic command-line text editor written in Rust

## FEATURES

- Add, Edit, and Delete lines
- Save file when done with it
- Prompts to Create file if file does not exist

## RUNNING IT
```bash
cargo run
```

You'll first be prompted to open a file to work with:
```
Enter filename to open. 'q' to quit: 
```

Then you'll be dropped into a simple menu
```
1. View File contents
2. Add line
3. Edit line
4. Delete line
5. Save
6. Quit
```
